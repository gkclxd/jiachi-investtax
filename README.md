# 重大決策前的架構診斷

> 在做重大決定之前，先看看還有哪些問題沒被想到。

一個給企業主、高資產家庭與家族企業使用的**投資架構與財稅風險檢視工具**。
它不計算稅額，而是在出售企業、設立投資公司、移轉股權或配置大筆資產之前，協助使用者在 3 分鐘內找出**值得先與會計師確認的架構議題**，並產生一份可以帶去會談的摘要。

線上版本：<https://jiachi-investtax.netlify.app/>

---

## 功能

### 1. 問答評估（約 3 分鐘）
以顧問式問答取代大量欄位，資產規模以區間表示，並可選擇「不透露」。

| 步驟 | 問題 |
|---|---|
| 1 | 您目前正在考慮什麼決定？（最多 2 個） |
| 2 | 相關的資產，大約落在哪個區間？ |
| 3 | 這些資產目前主要由誰持有？ |
| 4 | 下列哪些事，是您目前最不確定的？（最多 3 個） |
| 5 | 補充資訊（可略過）：公司營收、收益型態、盈餘傾向 |

### 2. 診斷結果
- 依使用者的決定、規模、持有方式與不確定事項，排序出 **3 個值得先確認的議題**
- 每個議題附「為什麼值得注意」與「常見情況」，不下最終結論
- 5 個建議帶去問會計師的問題
- 會談前可準備的資料清單

### 3. 進階分流地圖
「個人名義與營運中公司名義投資的架構分流」：輸入投資金額、年化收益率、股利占比、公司營收、申報方式、個人級距與盈餘處置，即時對照兩條課稅路徑的方向。

- 可從首頁直接進入，也可在診斷結果頁下方展開
- 年化收益率、股利占比會即時換算為年收益、股利股息與價差金額
- 網址加上 `?advisor=1` 時，結果頁的進階地圖會預設展開（供會計師或顧問面談使用）

### 4. 摘要輸出
- **下載診斷摘要（PDF）**：使用瀏覽器列印功能另存為 PDF，採適合列印的淺色版面，含會談筆記欄
- **傳送給會計師**：WhatsApp、Email 或複製文字

## 部署

### Netlify（連結 GitHub）
1. 在 Netlify 選擇 **Add new site → Import an existing project → GitHub**，選擇此 repository
2. 設定：
   - **Build command**：留空
   - **Publish directory**：`.`（repository 根目錄）
3. 部署完成後，之後每次 push 到主分支都會自動更新網站

### 其他靜態主機
GitHub Pages、Cloudflare Pages、Vercel 等皆可，直接以根目錄發布即可。

### 本機預覽
直接用瀏覽器開啟 `index.html`，或：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 自訂設定

所有可修改的內容都在 `index.html` 下方的 `<script>` 區塊。

### `CONFIG`：預約方式
```js
const CONFIG = {
  bookingUrl:  '',   // 預約表單網址；留空則不顯示預約按鈕
  email:       '',   // 預約用 Email；與 bookingUrl 皆留空則不顯示預約按鈕
  meetingNote: '...' // 預約卡片上的說明文字
};
```
`bookingUrl` 與 `email` 都留空時，網站只提供「下載摘要」與「傳送給會計師」，不會出現任何預約按鈕。

### `RULES`：法規門檻參數
判斷邏輯使用的門檻，例如擴大書審 3,000 萬上限、個人基本所得額免稅額、二代健保費率、營利事業最低稅負制等。
**請依財政部當年度公告確認後再使用。**

### `ISSUES`：議題文案
每個議題的標題、說明、常見情況與建議問題，可直接修改文字。

### `OPT`：問答選項
問答各步驟的選項文字。
